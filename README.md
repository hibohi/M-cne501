# Crack-It Academy — FINAL CLEAN

This is the single final project — premium UI, all features.

## What to use:
- index.html — OPEN THIS. Standalone app, works offline, no build needed. Just double-click.
  Saves progress to localStorage (Day X/80, streak, math history, XP, challenges).

- App.tsx — React source if you want to edit/dev

## How to dev (optional):
npm install
npm run dev  (put App.tsx in src/App.tsx or point vite to it)

## Features in this build:
- Premium UI (off-white #fbfaf8, rounded-2xl cards)
- Single eye blur block 👁️ for interviewer data + Sankey 8.8M→3.52M→1.58M→2.11M
- Human wording (no AI reek)
- 4-stage answering: Think 15 chars → Check Approach → Hints tiered → Full Explanation (interviewer lens, trap)

- Concepts & Frameworks: 25 concepts
- Challenges: 12 (Daily Micro, Weekly Battle, Math Blitz, Fermi Friday)
- Learning Modules: 8 modules with lessons + XP
- Save & Continue, Export JSON, 80-day plan with locks

No extra history files — this is it.
